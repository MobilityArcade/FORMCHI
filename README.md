# AKI 3.0

Voice-first living presence prototype.

## 3.0 changes
- Darker pearl-gray field for stronger iridescent contrast.
- Thin futuristic single-line AKI wordmark with a soft recessed/valley treatment.
- More visible breathing/expansion without adding UI.
- Faster conversational behavior: concise first response, low-latency turn-taking, and capped response length.
- Keeps listening / thinking / speaking visual states and conversational voice preference.

## Deploy
Keep `OPENAI_API_KEY` in Vercel Environment Variables. Replace `index.html`, `api/aki.js`, `package.json`, and this README, then redeploy.
