# AKI 4.4 — One Step + App Icon

AKI 4.4 keeps the 4.3 Black Iridescence design and 4.1 voice identity system, while adding the new interaction philosophy and installable app identity.

## New in 4.4
- AKI mark optically re-centered inside the sphere.
- Complex or overloaded questions are intentionally reduced to one useful thread at a time.
- AKI avoids long information dumps, identifies the root issue, and asks one simple question or gives one small next step.
- New AKI app icon: black field, iridescent ring, custom single-stroke AKI glyph.
- Apple touch icon + web app manifest are included so Add to Home Screen uses AKI branding.
- Existing black iridescent listening/thinking/speaking presentation, thinking chime, voice preferences, and English/Spanish preference behavior are retained.

## Deploy
Replace the current project files with this package and commit/push to GitHub. Let Vercel redeploy. Keep the existing OPENAI_API_KEY environment variable unchanged.

On iPhone Safari, open the deployed AKI site, use Share > Add to Home Screen. The AKI icon should be used for the installed shortcut.
