# AKI 4.3 — Black Iridescence Visual Upgrade

This package upgrades AKI 4.1 to the darker reference aesthetic: a true black liquid center, bright oil-on-black iridescent rim, subtle outer aura, and ultra-thin single-stroke AKI mark.

It preserves the 4.1 Live voice backend, voice preference switching, English/Spanish preference handling, listening/thinking/speaking states, and thinking chime. It also initializes the stored voice/language preference variables in the browser so those controls are available reliably.

## Deploy
Replace the existing project files with this package and redeploy on Vercel. Keep your existing `OPENAI_API_KEY` environment variable unchanged.

## Visual states
- Idle/listening: black center with slow liquid iridescent breathing
- Thinking: faster/brighter iridescent motion plus the short chime
- Speaking: brighter, more active living sphere

Version: AKI 4.3
